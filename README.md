# береста

Компилятор языка **береста** — с нуля, без зависимостей и без промежуточного C.
Свой синтаксис на русском, статическая типизация и нативная сборка в x86-64.

```
исходник.бер ──► лексер ──► парсер ──► семантика ──► кодогенерация
                                                          │
                                                          ▼
                                                 GNU as (x86-64)
                                                          │
                                                          ▼
                                                     ELF-бинарь
```

Компилятор написан на C++17/20 и сам испускает ассемблер. Затем `as` превращает
его в объектный файл, а `cc` — в обычный исполняемый файл ELF. Никакой
трансляции в C: на выходе честный машинный код.

## Быстрый старт

```sh
make                     # собрать компилятор в build/berestac
./build/berestac run examples/привет.бер
make install             # (по желанию) в /usr/local/bin/berestac
```

Вывод:

```
Здравствуй, мир!
Сумма квадратов от 1 до 5: 55
```

## Язык в двух минутах

```beresta
// Константа и функция.
устой СЕКРЕТ: число = 42;

дело приветствие(имя: строка) -> ничто {
    молви "Здравствуй, " + имя + "!";
}

береста {
    приветствие("мир");

    слово сумма: число = 0;
    повтор i от 1 до 5 {
        сумма = сумма + i * i;
    }

    ежели сумма > 50 {
        молви "Много: " + к_строке(сумма);
    } инако {
        молви "Мало.";
    }
}
```

Точка входа — обязательный блок `береста { ... }`. Это аналог `main`.

### Слова языка

| Слово | Смысл |
|---|---|
| `слово x: число = 1;` | объявить переменную |
| `слово a: [10]число;` | объявить массив |
| `a[i]` | элемент массива |
| `устой X: число = 1;` | объявить константу (только литерал) |
| `дело f(a: число) -> число { ... }` | объявить функцию |
| `береста { ... }` | точка входа |
| `молви expr;` | напечатать значение и перевод строки |
| `ежели` / `инако` / `инако ежели` | ветвление |
| `доколе expr { ... }` | цикл с условием |
| `повтор i от a до b шаг s { ... }` | цикл по числу, границы включительно |
| `для каждого x из a { ... }` | обойти массив |
| `вернуть expr;` | вернуть значение |
| `прервать;` / `продолжить;` | break / continue |
| `x += 1;` и родственные | присваивание с операцией |
| `правда` / `кривда` | true / false |
| `и` / `или` / `не` | логика (ленивая) |
| `ничто` | отсутствие значения |

### Типы

`число` (int64), `дробь` (double), `строка` (UTF-8), `флаг` (bool), `ничто` (void).

`число` неявно расширяется до `дроби`, обратно — только через отдельное
преобразование (в планах). Смешивать строку с числом через `+` нельзя:
используйте `к_строке`.

### Встроенные функции

| Функция | Что делает |
|---|---|
| `молви expr;` | печать (это оператор, а не функция) |
| `длина(строка) -> число` | длина в символах UTF-8 |
| `длина(массив) -> число` | количество элементов (известно при сборке) |
| `к_строке(значение) -> строка` | привести число/дробь/флаг к строке |
| `из_строки(строка) -> число` | разобрать целое число |
| `внемли() -> строка` | прочитать строку со стандартного ввода |
| `слушает(путь) -> строка` | прочитать файл целиком |
| `патриот(путь) -> строка` | то же самое, второе имя |
| `пишет(путь, текст) -> флаг` | записать строку в файл |
| `в_число(дробь) -> число` | отбросить дробную часть |
| `в_дробь(число) -> дробь` | расширить число до дроби |

### Массивы

```beresta
слово кубы: [10]число;
повтор i от 0 до 9 {
    кубы[i] = i * i * i;
}

для каждого куб из кубы {
    молви к_строке(куб);
}
```

- Длина задаётся литералом: `[10]`.
- Элементы по умолчанию: `0`, `0.0`, `""`, `кривда`.
- Индекс проверяется в рантайме: выход за границы — паника.
- Массив нельзя присвоить целиком или напечатать — только элементы.

### Присваивание с операцией

`x += 2;`, `x -= 1;`, `x *= 3;`, `x /= 2;`, `x %= 5;` — краткая запись
`x = x <операция> ...`.


## Команды

```sh
berestac build <файл.бер> [-o <бинарник>] [-S] [--keep-asm] [--asm <файл.s>]
berestac run   <файл.бер>
berestac check <файл.бер>          # только фронтенд, без сборки
berestac asm   <файл.бер> [-o <файл.s>]
berestac tokens <файл.бер>         # дамп токенов
berestac ast    <файл.бер>         # дамп дерева
berestac version
```

`-S` останавливается на ассемблере, `--keep-asm` сохраняет `.s` рядом с
исходником. Без `-o` бинарник кладётся рядом с исходником и называется так же,
только без расширения.

## Ошибки

Диагностика показывает место и подсказку:

```
ошибка: «х» объявлена как число, а значение типа строка
  --> ошибка.бер:6:22
   |
 6 |     слово х: число = "строка";
   |                      ^
  подсказка: положите сюда число или смените тип переменной
```

## Устройство проекта

```
src/
  lexer.cpp        исходник → токены
  parser.cpp       токены → AST
  sema.cpp         типы, области видимости, проверки
  codegen.cpp      AST → x86-64 (AT&T), включая рантайм на ассемблере
  driver.cpp       .s → .o → ELF, временные файлы
  dump.cpp         отладочный дамп AST
  main.cpp         CLI
examples/          живые программы на бересте
docs/              спецификация, грамматика, устройство бэкенда, планы
editors/vim/       подсветка синтаксиса
```

## Что уже есть и чего нет

Есть: статическая типизация, рекурсия, функции до 6 обычных и 8 дробных
параметров, циклы, массивы с проверкой границ, строки UTF-8, ввод-вывод и работа
с файлами, константы, ленивые `и`/`или`, составное присваивание, понятная
диагностика, паника при делении на ноль и выходе за границы.

Пока нет: структур, указателей, срезов, модулей, замыканий, сборки мусора,
оптимизаций, собственного ассемблера (используется GNU as). Массивы — только
локальные и фиксированной длины; массивы нельзя передавать в функции. Строки
живут в куче и не освобождаются — для учебного компилятора это осознанный
компромисс.
