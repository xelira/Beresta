# Планы

Цель проекта — язык, который умеет собирать сам себя и не зависит от C
как промежуточного слоя.

## 0.1 — сделано

- [x] Лексер, парсер, семантика, диагностика с позицией.
- [x] Типы `число`, `дробь`, `строка`, `флаг`, `ничто`.
- [x] Функции, рекурсия, константы, точка входа `береста`.
- [x] Ветвления, `доколе`, `повтор`, `прервать`, `продолжить`.
- [x] Строки UTF-8, конкатенация, сравнение, длина.
- [x] Ввод-вывод: `молви`, `внемли`, `из_строки`, `к_строке`.
- [x] Бэкенд x86-64 → GNU as → ELF.
- [x] Рантайм на ассемблере.
- [x] Массивы фиксированной длины, `для каждого`, проверка границ.
- [x] Файлы: `слушает`, `патриот`, `пишет`.
- [x] Явные преобразования `в_число`, `в_дробь`.
- [x] Составное присваивание `+=`, `-=`, `*=`, `/=`, `%=`.
- [x] Уклады (`уклад`) с полями простых типов.
- [x] Словарь фраз `мова`.
- [x] Только кириллица в исходниках, ошибка «пиши на русском».
- [x] Установщик на Go: Linux и Windows, нативный режим и `--wsl`.
- [x] Windows-бэкенд: Microsoft x64, PE32+, рантайм на C, нативный `berestac.exe`.
- [x] Автоматическая сборка мусора: консервативный mark-sweep, `собрать()`, `память()`.
- [x] Лаунчер `beresta`: файл или папка → сборка → запуск с выводом.
- [x] Лаунчер с вложенным компилятором (`go:embed`) и бандл в релизе.

## 0.2 — типы и данные

- [x] Массивы: `слово а: [10]число;`, индексация `а[индекс]`, длина.
- [x] Структуры: `уклад Точка { х: дробь; у: дробь; }`.
- [x] Массивы в параметрах функций (по ссылке, длина проверяется).
- [x] Уклады в параметрах функций (по ссылке).
- [x] Указатели: `указатель T`, `адрес`, `по`, проверка пустого указателя.
- [x] Указатели на уклады: `указатель Точка`, доступ `п.поле`.
- [ ] Срезы.
- [x] `для каждого` по массиву.
- [ ] Строки как структура «данные + длина + ёмкость».
