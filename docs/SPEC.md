# Спецификация языка береста

Версия 0.1.0. Документ описывает ровно то, что реализовано в компиляторе.

## 1. Исходники

- Кодировка: UTF-8. Расширение файлов: `.бер`.
- Только кириллица: латинская буква вне строки или комментария — ошибка
  «пиши на русском».
- Регистр значим: `Имя` и `имя` — разные имена.
- Пробелы, табуляции и переводы строк разделяют лексемы и больше ничего не значат.
- Комментарии: `// до конца строки` и `/* до закрывающей пары */`. Вложенности нет.
- Точка с запятой `;` завершает простой оператор.
- Блоки выделяются `{ }`.

## 2. Лексемы

### Идентификаторы

Начинаются с буквы (любой Unicode, включая кириллицу) или `_`, продолжаются
буквами, цифрами и `_`.

### Ключевые слова

```
слово устой дело береста
ежели инако доколе повтор от до шаг
вернуть прервать продолжить
молви
правда кривда и или не
число дробь строка флаг ничто
```

Ключевое слово нельзя использовать как имя.

### Числа

- Целое: последовательность десятичных цифр, `_` внутри разрешён: `1_000_000`.
- Дробное: целая часть, точка и хотя бы одна цифра после неё: `3.14`, `0.5`.
  Экспоненциальная запись (`1e9`) не поддерживается.
- Знак — это унарный оператор, а не часть литерала.

Диапазон целых: знаковый 64-битный. Дробные — IEEE-754 double.

### Строки

Двойные кавычки. Поддерживаются escape-последовательности:

| Запись | Значение |
|---|---|
| `\n` | перевод строки |
| `\t` | табуляция |
| `\r` | возврат каретки |
| `\0` | нулевой байт |
| `\\` | обратная косая черта |
| `\"` | кавычка |

Строка не может содержать неэкранированный перевод строки. Строки неизменяемы,
сравниваются по значению, склеиваются оператором `+`.

## 3. Типы

| Тип | Представление | Значения |
|---|---|---|
| `число` | int64 | целые |
| `дробь` | double | дробные |
| `строка` | указатель на UTF-8 | текст |
| `флаг` | bool | `правда`, `кривда` |
| `ничто` | — | отсутствие значения |
| `массив` | N слотов на стеке | N элементов одного типа |
| `уклад` | слоты по числу полей | структура с именованными полями |
| `указатель T` | адрес | ссылка на значение типа T |

Правила:

- Переменная не может иметь тип `ничто`.
- `число` неявно приводится к `дробь` при присваивании и в арифметике.
  Обратное преобразование неявным не бывает.
- Логические операторы требуют `флаг` с обеих сторон.
- Условия `ежели` и `доколе` обязаны быть `флагом`. Число условием не является.

## 4. Объявления верхнего уровня

На верхнем уровне разрешены только `привлечь`, `уклад`, `устой`, `дело` и ровно
один блок `береста`. Порядок произволен, но точка входа обязательна.

### Уклады

```
уклад Точка {
    х: дробь;
    у: дробь;
}
```

- Поле — простой тип (`число`, `дробь`, `строка`, `флаг`) или уклад,
  объявленный выше в файле.
- Поля-массивы и поля-указатели не поддерживаются.
- Пустых укладов и повторяющихся полей быть не может.
- Смещения полей считаются рекурсивно: вложенный уклад занимает столько слотов,
  сколько нужно его полям.
- Доступ к вложенному полю — цепочкой: `т.цвет.р`.
- Уклад описывает тип; переменные этого типа создаются через `слово`.

### Константы

```
устой ИМЯ: тип = литерал;
```

Значением может быть только литерал (число, дробь, строка, флаг) или унарный
минус перед числовым литералом. Константы неизменяемы и видны во всей программе.

### Указатели

```
слово х: число = 42;
слово п: указатель число = адрес х;

молви к_строке(по п);
по п = 100;
```

- `указатель T` — адрес значения типа `T`, где `T` — `число`, `дробь`, `строка`
  или `флаг`.
- `адрес` берёт адрес переменной, элемента массива или поля уклада.
- `по` читает значение по указателю; `по п = ...` записывает.
- Указатели передаются в функции как обычные параметры.
- Указатель на уклад: `указатель Точка`; поля — через `п.поле`.
- Указатели на массивы и указатели на указатели не поддерживаются.
- Арифметики указателей нет; возвращать указатели из функций нельзя.
- Разыменование нулевого указателя — паника.

### Функции

```
дело имя(параметр: тип, ...) -> тип {
    ...
}
```

- Тип возврата указывается всегда; для отсутствия значения — `ничто`.
- Параметры передаются по значению, кроме массивов и укладов: они передаются
  по ссылке (указатель на данные).
- Параметр-массив записывается как `[N]тип`, параметр-уклад — именем уклада.
- Ограничение бэкенда: не более 6 параметров типов, отличных от `дроби`,
  и не более 8 параметров-дробей одновременно. Массив и уклад считаются как
  один обычный параметр.
- Функция с типом, отличным от `ничто`, обязана содержать хотя бы один
  `вернуть` (проверяется статически).
- Рекурсия разрешена, функции видны до своего объявления.

## 5. Модули

```
привлечь "математика.бер";
```

- `привлечь` — отдельная строка верхнего уровня.
- Путь относителен каталога текущего файла.
- Повторное подключение игнорируется, циклы — ошибка.
- Объявления модуля попадают в общий глобальный слой.
- Диагностика указывает на исходный файл модуля и локальную строку.

## 6. Операторы

### Переменные

```
слово имя: тип;                 // значение по умолчанию
слово имя: тип = выражение;
имя = выражение;                // только для существующей изменяемой переменной
```

Значения по умолчанию: `0`, `0.0`, `""`, `кривда`.

Присваивание с операцией `+=`, `-=`, `*=`, `/=`, `%=` — краткая запись
`х = х <операция> значение;`.

### Массивы

```
слово а: [10]число;
а[0] = 42;
молви к_строке(а[0]);
```

- Длина — целочисленный литерал от 1 до 100000, известна при компиляции.
- Тип элемента — любой, кроме `ничто`.
- Элементы инициализируются нулями, пустыми строками или `кривдой`.
- Индексация только у имени массива: `а[индекс]`, без вложенности.
- Индекс обязан быть типа `число`; проверяется в рантайме.
- Выход за границы — паника.
- Массив целиком нельзя присвоить, передать в функцию или напечатать.
- Массив можно передать в функцию по ссылке: `дело ф(а: [5]число)`. Длина и тип
  элемента обязаны совпадать с объявлением параметра.
- Изменения элементов внутри функции видны вызывающему.

### Уклады

```
слово т: Точка;
т.х = 3.0;
молви к_строке(т.у);
```

- Переменная уклада заполняется по полям.
- Обращение к полю: `имя.поле`; цепочки не поддерживаются.
- Уклад можно передать в функцию по ссылке: `дело ф(т: Точка)`; изменения полей
  видны вызывающему.
- Уклад инициализируется значениями по умолчанию для типов полей.

### Печать

```
молви выражение;
```

Печатает значение и перевод строки. Выражение типа `ничто` печатать нельзя.

### Ветвление

```
ежели условие {
    ...
} инако ежели условие {
    ...
} инако {
    ...
}
```

Ветка `инако` необязательна.

### Цикл с условием

```
доколе условие {
    ...
}
```

### Цикл по числу

```
повтор номер от начало до конец шаг шаг {
    ...
}
```

- `начало` и `конец` — выражения типа `число`, вычисляются один раз.
- `шаг` необязателен (по умолчанию 1), тоже вычисляется один раз.
- Границы включительно. При отрицательном шаге счёт идёт вниз.
- Шаг-литерал `0` — ошибка компиляции; нулевой шаг в рантайме — паника.

### Обход массива

```
для каждого элемент из массив {
    ...
}
```

- Перебирает элементы по порядку, копируя значение в переменную цикла.
- Переменная цикла живёт в области видимости тела.
- `прервать` и `продолжить` работают как в остальных циклах.
- Изменение переменной цикла не меняет массив.

### Возврат и управление

```
вернуть выражение;
вернуть;                 // только в функции типа ничто
прервать;                // выход из ближайшего цикла
продолжить;              // к следующей итерации
```

`прервать` и `продолжить` вне цикла — ошибка компиляции.

### Блок

`{ ... }` — самостоятельный оператор. Создаёт новую область видимости.

## 6. Выражения

Приоритеты от слабого к сильному:

| Приоритет | Операторы |
|---|---|
| 1 | `или` |
| 2 | `и` |
| 3 | `==`, `!=` |
| 4 | `<`, `<=`, `>`, `>=` |
| 5 | `+`, `-` |
| 6 | `*`, `/`, `%` |
| 7 | унарные `-`, `!`, `не`, `адрес`, `по` |

Все бинарные операторы левоассоциативны.

- `+` для строк — конкатенация, для чисел — сложение.
- `%` определён только для `число`.
- `/` для целых — целочисленное деление; деление на ноль — паника в рантайме.
- Сравнения дают `флаг`. Строки сравниваются лексикографически по байтам.
- `и` и `или` вычисляются лениво и возвращают `флаг`.
- `!` и `не` — синонимы.

## 7. Области видимости

- Верхний уровень: константы и функции.
- Слой встроенных функций находится выше пользовательского: своё `дело` может
  перекрыть встроенное имя.
- Блок `береста` — своя область.
- Тело функции — своя область, параметры в ней.
- Каждый блок `{ }` и тело цикла `повтор` создают область.
- Внутренняя область может перекрывать имя внешней (`затенение`).
- Повторное объявление в одной области — ошибка.
- Переменная видна только после своего объявления.

## 8. Встроенные функции

| Сигнатура | Поведение |
|---|---|
| `длина(строка) -> число` | количество символов UTF-8 |
| `длина(массив) -> число` | количество элементов, известно при компиляции |
| `к_строке(число) -> строка` | десятичная запись |
| `к_строке(дробь) -> строка` | до 15 значащих цифр |
| `к_строке(флаг) -> строка` | `правда` или `кривда` |
| `к_строке(строка) -> строка` | тождество |
| `из_строки(строка) -> число` | разбор префикса; при мусоре вернёт 0 |
| `внемли() -> строка` | строка со stdin без `\n`; в конце файла — пустая строка |
| `слушает(путь) -> строка` | содержимое файла целиком; нет файла — пустая строка |
| `патриот(путь) -> строка` | второе имя для `слушает` |
| `пишет(путь, текст) -> флаг` | записать файл; `кривда` при ошибке |
| `в_число(дробь) -> число` | отбросить дробную часть |
| `в_дробь(число) -> дробь` | расширить число до дроби |
| `мова(ключ) -> строка` | фраза из словаря; неизвестный ключ — пустая строка |

Фразы `мова`: `привет`, `прощание`, `спасибо`, `пожалуйста`, `да`, `нет`,
`береста`, `тишина`, `ошибка`, `дорога`, `утро`, `вечер`.

Встроенные имена можно затенять своими функциями — тогда используется ваша.

## 9. Ошибки времени выполнения

- Деление на ноль и остаток от деления на ноль.
- Нулевой шаг цикла `повтор`, вычисленный в рантайме.
- Выход индекса за границы массива.
- Разыменование пустого указателя.

Сообщение печатается в stderr с префиксом `береста:` и кодом выхода 1.

## 10. Память

Строки размещаются в куче и освобождаются автоматически.

- Сборщик консервативный, mark-sweep: корни — слова на стеке, блоки — строки.
- Сборка запускается сама при превышении порога выделенной памяти.
- Вручную: `собрать();`. Посмотреть живые байты: `память()`.
- Порог после сборки — не меньше 1 МБ и не меньше удвоенного объёма живых
  данных.
- Ложные удержания возможны: число на стеке, похожее на адрес, может
  задержать блок до следующей сборки. Это обычная цена консервативного GC.
- Циклов в данных нет: строки не ссылаются друг на друга, поэтому утечек
  из-за циклов не бывает.
- Указатели не меняют правила: `free` не нужен, память освобождает сборщик.
  Указатель на локальную переменную живёт, пока жива её область видимости;
  после выхода из блока такой указатель становится висячим.
