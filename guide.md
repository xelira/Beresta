# Гайд по бересте

Пошаговое руководство: от установки до программы с модулями, массивами,
укладами и указателями. Полный справочник языка лежит в [ЯЗЫК.md](ЯЗЫК.md),
здесь — практика.

---

## 1. Что это

Береста — компилируемый язык с русским синтаксисом. Компилятор написан на C++,
испускает ассемблер x86-64 и собирает обычный исполняемый файл ELF. Память
строк освобождается автоматически: `free` писать не нужно.

Главное правило: **исходники пишутся кириллицей**. Латинская буква вне строки и
комментария — ошибка «пиши на русском».

---

## 2. Установка

### Linux, самый простой путь

Скачать из релизов `beresta-linux-amd64` — это один файл, внутри уже лежит
компилятор:

```sh
chmod +x beresta-linux-amd64
./beresta-linux-amd64 version
```

Для сборки программ нужны ассемблер и линкер (`as`, `cc`). Их ставит установщик:

```sh
./beresta-install-linux-amd64
```

Установщик сам скачает исходники, поставит зависимости (если запущен от root) и
положит `berestac` в `~/.local/bin`.

### Из исходников

```sh
git clone https://github.com/xelira/Beresta.git
cd Beresta
make                      # build/berestac
make launcher             # build/beresta
make launcher-bundle      # build/beresta-bundle — компилятор внутри
```

### Windows

Запустить `beresta-install-windows-amd64.exe`. Установщик работает нативно:

1. скачивает компилятор `berestac-windows-amd64.exe`;
2. скачивает портативный MinGW-w64 (ассемблер и линкер);
3. ставит всё в `%LOCALAPPDATA%\beresta`;
4. добавляет каталоги в пользовательский PATH.

После этого в новом терминале:

```bat
beresta version
beresta new моя_программа
beresta run моя_программа
```

Собираются настоящие Windows `.exe` (PE32+, Microsoft x64). WSL не нужен.

Если нативный режим не завёлся, есть запасной:

```bat
beresta-install.exe --wsl
```

## 3. Первая программа

```sh
beresta new моя_программа
cd моя_программа
beresta run .
```

`beresta new` создаёт `главная.бер`:

```beresta
// Новая программа на бересте.

береста {
    молви "Здравствуй, береста!";
}
```

`береста { ... }` — обязательная точка входа, аналог `main`.

Запустить один файл:

```sh
beresta run главная.бер
```

Собрать бинарник без запуска:

```sh
beresta build главная.бер -o моя_программа
./моя_программа
```

## 4. Переменные и типы

```beresta
береста {
    слово имя: строка = "Аня";
    слово возраст: число = 21;
    слово рост: дробь = 1.72;
    слово студент: флаг = правда;

    молви имя + ", " + к_строке(возраст);
}
```

| Тип | Что хранит | По умолчанию |
|---|---|---|
| `число` | целое 64 бита | `0` |
| `дробь` | дробное | `0.0` |
| `строка` | текст UTF-8 | `""` |
| `флаг` | `правда` / `кривда` | `кривда` |
| `ничто` | ничего, только для функций | — |

Присваивание:

```beresta
возраст = 22;
возраст += 1;   // то же, что возраст = возраст + 1;
```

Нельзя положить строку в число и наоборот. Число само расширяется до дроби,
обратно — только через `в_число(дробь)`.

---

## 5. Условия и циклы

```beresta
береста {
    слово х: число = 7;

    ежели х > 0 {
        молви "плюс";
    } инако ежели х < 0 {
        молви "минус";
    } инако {
        молви "ноль";
    }

    повтор номер от 1 до 5 {
        молви к_строке(номер);
    }

    слово пока: число = 3;
    доколе пока > 0 {
        молви к_строке(пока);
        пока -= 1;
    }
}
```

- `повтор` включает обе границы;
- шаг можно задать: `повтор номер от 10 до 0 шаг -2`;
- `прервать` — выйти из цикла, `продолжить` — следующая итерация.

---

## 6. Функции

```beresta
дело сумма(а: число, б: число) -> число {
    вернуть а + б;
}

дело привет(имя: строка) -> ничто {
    молви "Здравствуй, " + имя + "!";
}

береста {
    привет("мир");
    молви к_строке(сумма(2, 3));
}
```

- тип возврата обязателен;
- функция с типом, отличным от `ничто`, должна что-то вернуть;
- рекурсия разрешена;
- своё `дело` может перекрыть встроенную функцию.

## 7. Массивы

```beresta
береста {
    слово кубы: [10]число;

    повтор номер от 0 до 9 {
        кубы[номер] = номер * номер * номер;
    }

    слово итог: число = 0;
    для каждого значение из кубы {
        итог += значение;
    }

    молви "сумма: " + к_строке(итог);
    молви "длина: " + к_строке(длина(кубы));
}
```

- длина задаётся литералом: `[10]`;
- индекс проверяется: выход за границы — паника;
- массив передаётся в функцию по ссылке, длина должна совпадать:

```beresta
дело сумма(а: [5]число) -> число {
    слово итог: число = 0;
    для каждого значение из а {
        итог += значение;
    }
    вернуть итог;
}
```

## 8. Уклады (структуры)

```beresta
уклад Точка {
    х: дробь;
    у: дробь;
    имя: строка;
}

береста {
    слово т: Точка;
    т.х = 3.0;
    т.у = 4.0;
    т.имя = "вершина";

    молви т.имя + ": " + к_строке(т.х) + ", " + к_строке(т.у);
}
```

- поля только простых типов;
- уклад целиком не печатается и не присваивается — только поля;
- уклад передаётся в функцию по ссылке: `дело сдвинуть(т: Точка)`.

---

## 9. Указатели

Указатели тоже на русском: `указатель`, `адрес`, `по`.

```beresta
береста {
    слово х: число = 42;
    слово п: указатель число = адрес х;

    молви к_строке(по п);   // 42

    по п = 100;             // запись по адресу
    молви к_строке(х);      // 100
}
```

Указатель на уклад — поля через точку:

```beresta
уклад Точка { х: число; у: число; }

береста {
    слово т: Точка;
    слово п: указатель Точка = адрес т;

    п.х = 10;
    молви к_строке(т.х);   // 10
}
```

Правила:

- `адрес` берётся у переменной, элемента массива или поля уклада;
- `по` разыменовывает указатель на простое значение;
- уклад по указателю читается и пишется через `п.поле`;
- пустой указатель при разыменовании даёт панику «пустой указатель»;
- арифметики указателей нет;
- указатели на массивы и на другие указатели не поддерживаются.

Указатели не требуют освобождения памяти: на стек и на строки правило одно —
`free` не нужен.

## 10. Модули

Большая программа раскладывается по файлам:

```
моя_программа/
├── главная.бер
├── математика.бер
└── приветствие.бер
```

`математика.бер`:

```beresta
устой ПИ: дробь = 3.14159;

дело квадрат(н: число) -> число {
    вернуть н * н;
}
```

`главная.бер`:

```beresta
привлечь "математика.бер";
привлечь "приветствие.бер";

береста {
    привет("мир");
    молви "квадрат: " + к_строке(квадрат(7));
}
```

- путь относителен текущего файла;
- повторное подключение игнорируется;
- циклы подключений — ошибка;
- имена общие для всей программы: два одинаковых `дело` — ошибка;
- диагностика указывает на настоящий файл модуля и его строку.

Запуск папки:

```sh
beresta run моя_программа
```

## 11. Ввод, файлы, фразы

```beresta
береста {
    молви "Как тебя зовут?";
    слово имя: строка = внемли();
    молви "Привет, " + имя;
}
```

```beresta
береста {
    слово текст: строка = слушает("заметка.txt");
    молви текст;

    слово ок: флаг = пишет("копия.txt", текст + "\nдописано");
    молви "записано: " + к_строке(ок);
}
```

`патриот(путь)` — второе имя для `слушает`.

Фразы:

```beresta
молви мова("привет");   // Здравствуй, путник.
молви мова("дорога");   // Дорога зовёт.
```

Полный список фраз — в [ЯЗЫК.md](ЯЗЫК.md).

## 12. Память

Писать `free` не нужно. Строки освобождает консервативный mark-sweep сборщик:

- сборка запускается сама при превышении порога;
- вручную: `собрать();`
- посмотреть живые байты: `память()`.

```beresta
береста {
    слово с: строка = "";
    повтор номер от 1 до 5000 {
        с = "мусор " + к_строке(номер);
    }
    собрать();
    молви "живо: " + к_строке(память());
}
```

Указатель на локальную переменную живёт, пока жива её область видимости. После
выхода из блока такой указатель становится висячим — это единственное, за чем
стоит следить самому.

## 13. Ошибки

Ошибка компиляции показывает файл, строку, фрагмент и подсказку:

```
ошибка: «х» объявлена как число, а значение типа строка
  --> пример.бер:6:22
   |
 6 |     слово х: число = "строка";
   |                      ^
  подсказка: положите сюда число или смените тип переменной
```

Ошибки времени выполнения:

| Сообщение | Причина |
|---|---|
| `береста: деление на ноль` | `/` на ноль |
| `береста: остаток от деления на ноль` | `%` на ноль |
| `береста: шаг повтора равен нулю` | нулевой шаг в рантайме |
| `береста: выход за границы массива` | индекс вне `[0, N)` |
| `береста: пустой указатель` | `по` у нулевого указателя |

Код выхода — `1`.

## 14. Команды

Лаунчер:

```sh
beresta run <файл.бер | папка>
beresta build <файл.бер | папка> [-o выход]
beresta check <файл.бер | папка>
beresta new <папка>
beresta doctor
```

Компилятор:

```sh
berestac build файл.бер [-o бинарник] [-S] [--keep-asm]
berestac run файл.бер
berestac check файл.бер
berestac asm файл.бер -o файл.s
berestac tokens файл.бер
berestac ast файл.бер
```

`beresta doctor` показывает, что найдено:

```
береста 0.4.0
система: linux/amd64
компилятор: /home/user/.cache/beresta/bin/berestac
as: /usr/bin/as
cc: /usr/bin/cc
```

## 15. Частые проблемы

**«пиши на русском»** — в исходнике латинская буква. Имена только кириллицей:
`слово имя`, а не `слово name`. Латиница разрешена в строках и комментариях.

**«не найден berestac»** — лаунчер не видит компилятор. Проверьте
`beresta doctor`, поставьте `BERESTAC=/путь/к/berestac` или запустите установщик.

**«ассемблер не принял сгенерированный код»** — это баг компилятора, а не вашей
программы. Сохраните `.s` через `berestac build файл.бер -S` и приложите к issue.

**«нет блока береста»** — добавьте точку входа:

```beresta
береста {
    // код
}
```

**Кракозябры вместо русского** — файл должен быть в UTF-8.

**Windows: не находится `as` или `gcc`** — переустановите `beresta-install.exe`: он скачивает MinGW в `%LOCALAPPDATA%\\beresta\\toolchain` и прописывает PATH. После установки откройте новый терминал.
